# Superseded RSR recipe

`train_rsr.mixed30.tsv` is the 3,489-row replacement mixture generated on
2026-10-24 before the additive recipe was adopted. It replaces selected base
inputs with marked inputs. It is retained only as a historical artifact;
do not use it for current training. The active builder writes
`repair_data_gen/rsr_generation/dataset/train_rsr.augmented.tsv` instead.
